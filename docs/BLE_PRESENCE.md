# 휴대폰 직접 페어링 감지

보드와 Fold7을 기본 Bluetooth 설정으로 직접 페어링하고, 등록된 폰의 인증된 실제 연결로 LCD를 제어한다. PC 1대와 폰 1대의 본딩·연결을 따로 관리하며 PC 사용량 전송은 계속된다. 추가 휴대폰 앱·Wi-Fi·광고 이름/별칭 감지는 사용하지 않는다.

## 사용법

1. LCD의 **BLE 연결 → 휴대폰 감지 → 휴대폰 등록**에서 2분 등록 창을 연다.
2. Fold7 기본 Bluetooth 설정에서 Quotamon을 선택하고 양쪽 6자리 번호가 일치할 때만 각각 승인한다.
3. **휴대폰 감지 사용**을 켠다. 등록·삭제·이 설정은 보드에 저장한다. PC 화면에서는 연결 상태를 확인한다.
4. 휴대폰 연결 해제부터 60초 후 LCD를 끄고 자동 재연결 시 켠다. 실제 이동부터 해제까지는 Bluetooth 링크 시간 초과가 추가된다.
5. 화면 끄기 예약이 우선한다. 꺼진 화면을 터치하면 원래 밝기로 5분간 켜지고 조건을 다시 평가한다.

Fold7 기본 OS의 자동 연결을 위해 사용자가 승인한 HID 소비자 제어 프로파일을 사용한다. 키보드·마우스 컬렉션과 자동 입력 전송은 없다. 실제 배터리 잔량이나 Bluetooth 적합성 인증을 주장하지 않는다. 폰 원격 이름을 읽지 않아 PC에는 일반명 ‘등록된 휴대폰’으로 표시한다.

## 검증 상태

- B: 기본 설정 페어링·번호 비교·인증, 입력 정상, 잠금 30분, 조작 없는 실제 거리 복귀 1회, PC 사용량/ACK를 확인했다. 사용자 요청으로 실제 거리 왕복은 1회로 충족한다.
- 현재 설치 C: 사용량 자동 복구, 해제 후 60,088ms LCD 꺼짐, 자동 인증 후 66ms 켜짐, 터치 300,044ms 점등 후 꺼짐을 로그와 사용자 확인으로 통과했다. [C 실물 기록](ble-paired-presence-hardware.json).
- D: 구형 광고 설정·검색 API·목록을 제거하고 schema2 읽기 전용 PC 상태와 표시용 ID 마이그레이션을 구현했다. 펌웨어 업로드·읽기 검증과 PC 0.3.0 동일 경로 적용을 마쳤다. 전원 재연결 후 사용량/휴대폰 자동 연결·실제 ACK1건·PC의 연결/감지 켜짐 상태와 짧은 안정성을 확인했다. [D 실물 기록](ble-paired-migration-hardware.json). [D 빌드 기록](ble-paired-migration-build.json).
- 실물 예약 우선순위, 로컬 감지 스위치 재부팅 복원, PC 완전 종료 상태의 독립 동작 등 남은 E 항목은 미검증이다. 예약 실물 시험은 현재 사용자 사정으로 보류했고 원래 예약 켜짐18:00~07:00을 유지했다. 모의 검사를 실제 Android 결과로 대체하지 않는다.

구현·후속 절차는 [계획 18절](BLE_PAIRED_PRESENCE_PLAN.md#18-c-실물-결과와-d-설정ui-전환), wire 필드는 [BLE 프로토콜](BLE_PROTOCOL.md)을 따른다. [이전 광고 방식 기록](BLE_PRESENCE_SCAN_ARCHIVE.md)과 B/C 이미지별 기록은 이력으로 보존한다. 앱/NVS 백업에는 본딩 키가 있으므로 `.local` 밖으로 공개하지 않는다.
