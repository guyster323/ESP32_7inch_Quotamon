# UI 표시 일관성 수정

리셋권 만료 정보가 추가되면서 카드의 남은 높이로 막대와 캐릭터 크기를 다시 계산하던 것이 원인이었다. 작은 막대에서는 기존 퍼센트가 일반 글꼴로 바뀌고 한도 이름과 붙었으며, 캐릭터에도 임의 축소 배율이 적용됐다.

- 홈 캐릭터는 원본 88×108, 상세는 2배 크기로 고정한다. 픽셀 그림에 임의 축소를 적용하지 않는다.
- 홈 막대는 높이 51px, 숫자는 기존 25px 픽셀 글꼴을 유지한다. 상세 숫자는 기존 40px 글꼴이다. 채워진 부분의 흰 글자와 빈 부분의 어두운 글자를 유지한다.
- `무제한`, `<1%`는 문자 표현이 가능한 본문 글꼴로 표시하고 실제 글꼴 높이에 맞춰 정렬한다.
- 5개 계정을 표시할 때도 Codex 3개 카드 각각에 리셋권 만료 정보 2줄과 Plan 리셋 시기를 함께 표시한다. 리셋권이 있는 첫 행은 높이 206px, 아래 행은 158px로 배분하고 본문 시작 위치를 조정한다. 캐릭터·퍼센트·막대 크기는 유지한다.
- 리셋권은 `R.T.1`, `R.T.2`와 남은 시간만 표시한다. 0분은 적색, 14일은 초록색으로 연속 보간하고 14일 이상은 초록색을 유지한다. 만료된 항목은 적색 `0m`, 시각이 없으면 중립색이다. 날짜·시간대는 홈·상세·웹에서 표시하지 않는다.
- 홈 카드 제목 오른쪽의 중복 안내인 `리셋권` 배지는 표시하지 않는다.
- Codex는 `Plan 5h : 3h 54m | W 1d 8h` 형식이다. 5시간·7일을 각각 최대 적색, 0분을 최소 초록색으로 보간하며 두 시간의 색상은 독립적이다.
- Cursor와 Copilot은 `Plan Reset M : 16d 0h` 형식이다. 30일을 최대 적색, 0분을 최소 초록색으로 보간한다. 알 수 없는 시각·리셋 후 확인 대기 문구는 중립색이다.
- 4개 계정이거나 아래 행에도 리셋권이 있으면 높이 184px 카드를 사용하고 남은 시간 두 개를 가로로 배치한다. 좁은 줄에서는 `1d6h5m`처럼 단위 사이 공백을 줄여 두 이름과 시간을 함께 표시한다. 카드가 작다는 이유로 남은 시간을 숨기지 않는다.
- Copilot은 퍼센트와 `Plan Reset` 남은 시간을 표시한다. 월간·Session AIC 수치와 해당 표시 설정은 화면에서 제거한다. 기존 설정·전송 형식은 계속 읽을 수 있다.
- 작은 카드의 긴 리셋 안내는 말줄임하고 상세에서 확인한다. 추가 한도 수도 제목 옆에 표시해 기존 막대와 그림의 영역을 보존한다.
- 새 번역 문구를 포함하도록 14/16/20px 내장 글꼴을 재생성한다. 웹의 버튼과 제목도 기존 크기로 복원한다.

검증: `python tools/verify_ui_consistency.py --simulator build/native-lcd/espmonitor_sim.exe`.
공유 LVGL 렌더러에서 Codex 3개에 서로 다른 만료 정보를 넣어 카드별 정보가 독립적으로 보이는지 검사한다. 글꼴, 배율, 막대 크기, 상세 스크롤, 숫자 잘림, 다국어, 계정 수와 애니메이션도 검사한다. 결과와 화면은 `visuals/ui-consistency/`에 저장한다. 테스트는 예시 데이터이며 실물 표시 검증과 펌웨어 업로드를 대신하지 않는다.
